There are many things that people LOVE to have on websites that are really just easier to avoid than to try to implement in a usable, responsive, and accessible way. General Tips

There are a lot of tags within HTML, and some of them are more useful than others. A good general rule that I've found over my years in college has been to stop before you make something from scratch and look up if there's a tag for it already. Something like "article" or "main" can save some time creating and formatting a custom div.

An example of this could be trying to create a table using css because you don't know the table tag exists. Sure, it's possible, but it would be impossible for a screen reader to recognize it.

A perhaps more applicable example of this would be to just use h1, h2, h3 instead of adapting a font using classes and css. There's not any reason to create ".header1" since it's there and extremely recognizable by browsers and screen readers.

Images and Videos

Helpful Info

All images and videos must have the alt property with a description of the content represented. Alt text is necessary because it will allow screen-readers to present the information for users that have trouble with sight. Media with audio should have a transcript. Text in videos should meet the same contrast and size standards as the rest of the website, etc.


Another helpful tip for images and videos is that setting the width and height can keep the page from moving pieces around as they load. If the height and width are set in the code, the page allocates the space automatically instead of doing it when the media is loaded.

Lists

Lists include html tags like ordered (ol), unordered (ul), and definition (dl) lists.


Helpful Info

Lists should represent data in a way that makes sense. Formatting something as a list when it isn't one can make things hard to read and understand.

Fonts

Helpful Info

Fonts should be simple. Sans-serif, not overly decorative, and should be at least 3/16 inch high based on the letter "I" (capital i). Verdana, the font used on this page, is a good font for this! Another benefit of the font is that it has a clear difference between lower case i, capital I, and lower case L.

Colors and Contrast

Helpful Info

One of the quickest ways to make sure that your website is accessible is making sure that people with vision problems will be able to interact with your page still. Vision can be a very tricky thing to anticipate, so the best practice is to make sure that your website utilizes high-contrast colors to ensure that someone who can't make out fine details will still be able to engage with the page.

The WCAG standards describe a ratio between the foreground and the background that determines if the contrast is high enough between the two parts to meet the standard, and a really quick way to know if your page is meeting these standards is to go to a website like WCAG Contrast Checker Tool and input the two colors you're trying to check.
